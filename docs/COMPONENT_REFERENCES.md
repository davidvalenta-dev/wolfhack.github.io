# Selected awesome-components references

Adapted from the rendered prompt references in wundercorp/awesome-components. No executable upstream source was supplied in these entries. The React implementations use PulseCast's own palette, research copy, and existing actions.

- [HextaUI command menu](https://github.com/wundercorp/awesome-components/blob/main/components/h/hextaui/command-menu/default/prompt.md): Quick find button, Cmd/Ctrl K shortcut, searchable research destinations, native modal focus containment, Escape dismissal and keyboard navigation.
- [Codehagen timeline](https://github.com/wundercorp/awesome-components/blob/main/components/c/codehagen/timeline/default/prompt.md): linked session moments, time labels, connected visual markers and responsive layout. Replaces the previous scene cards and drives the same synthetic replay.
- [Fuma Nama accordion](https://github.com/wundercorp/awesome-components/blob/main/components/f/fuma-nama/accordion/default/prompt.md): disclosure rows with accessible regions, chevrons and copy-link controls. Answers clarify public labels, synthetic signals, patient demo access and pending validation.

Implementation: `components/ui/research-explorer.tsx`. Existing React, Lucide and Tailwind dependencies are reused. Watch imagery remains removed.
